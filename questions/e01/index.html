Evaluation and safety

E01 Question

Which evaluators should run before every release?

Checked 12 Oct 2026 Ankur Napa

The answer

Foundry groups built-in evaluators into three families. The portal shows agent, quality and safety evaluators when you create an evaluation.

FamilyEvaluators to start with
AgentTask Adherence, Intent Resolution, Task Completion
Tool useTool Call Accuracy, Tool Selection, Tool Call Success
QualityGroundedness, Relevance, Coherence
SafetyViolence, Sexual, Self-harm, Hate and unfairness

Task Adherence, Task Completion and Intent Resolution are marked preview on Learn.

Two composite evaluators, Output Quality and Tool Use Quality, are in preview. Each batches several evaluators into one LLM judge call to cut cost and latency. It returns a pass only when every component passes.

Learn's observability guidance describes three stages: pick the base model, evaluate before production with your own data and the AI red teaming agent, then monitor in production with continuous and scheduled evaluation.

For the Harbour Goods agent, a release set of 50 to 100 real questions covering orders, delivery, returns and warranty is enough to start. Agree a pass threshold for each evaluator before the first run, then make the run a step in the release pipeline so a failed threshold stops the deploy.

Decision rule

Run task adherence, intent resolution and groundedness for quality. Add tool call accuracy if the agent uses tools, plus the safety evaluators. Gate the release on thresholds you agreed in advance.

Watch out

Several agent evaluators and the composite evaluators are in preview. An LLM judge is a model too, so keep a human-reviewed sample.
