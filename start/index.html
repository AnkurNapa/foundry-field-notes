Start here

Microsoft Foundry is where you build AI apps and agents on Azure. You pick models, ground them in your own data, give them tools, test them and ship them, all from one resource and one portal.

Foundry in four sentences

  • A Foundry resource in your Azure subscription holds one or more projects. A project is where a team works.
  • You deploy models from the catalogue into it. You pay for the tokens each call reads and writes.
  • An agent is a model with instructions, knowledge and tools that can take several steps towards a goal.
  • Before anything goes live you evaluate it, put guardrails on it and trace what it does.

You work in the portal at ai.azure.com or from code with the Foundry SDK. The official overview is What is Microsoft Foundry on Microsoft Learn.

Then pick a role path

Each path puts the roadmap steps in the order that role needs them, with the certification and a portfolio project.

  • AI engineer

    Builds grounded AI apps: models, prompts, retrieval and the code around them.

  • Agent developer

    Builds agents that use tools, follow workflows and hand over to people.

  • AI platform engineer

    Runs Foundry for many teams: identity, networks, quota, cost and deployment.

  • AI quality and evaluation engineer

    Decides when an AI app is good enough to ship, and proves it.

  • AI solution architect

    Designs the whole solution and makes the trade-offs a business can defend.
