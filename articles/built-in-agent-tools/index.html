Give an agent built-in tools: file search, code and web

Add file search, code interpreter and web search to the Harbour Goods support agent, then ask three questions and read the response to see which tool ran for each. With a 60-order sample file and the totals the agent should find.

12 Oct 2026 Foundry as of October 2026 Checked against Microsoft Learn Level 1 Ankur Napa AgentsToolsSDK

Short answer

Built-in tools are what turn the prompt agent from the last article into something that can look things up. Three cover most needs:

  • File search searches documents you upload into a vector store and quotes them.
  • Code interpreter writes and runs Python in a Microsoft-managed sandbox. Use it for sums, charts and file analysis.
  • Web search grounds answers in the public web through Grounding with Bing.

You attach tools to the agent. The model decides which to call for each question. You can see the decision: every tool call appears in the response output as an item with its own type, such as file_search_call, code_interpreter_call or web_search_call.

Two of these carry charges beyond tokens. File search and code interpreter both list additional charges on Learn. Web search sends the search query outside the Azure compliance boundary. Know all three before you attach anything.

This step maps to the AI-103 area "Build agents by using Foundry": integrating agent tools such as APIs, knowledge stores, search and custom functions.

Before you start

  • The agent and project from the previous article, with a gpt-5.4-mini deployment or another current chat model.
  • Foundry User on the project to create and run agents.
  • Storage Blob Data Contributor on the project's storage account. Learn lists it as required for uploading files for file search.
  • Python 3.10 or later, az login done and pip install "azure-ai-projects>=2.3.0" azure-identity.
  • Both sample files downloaded into your working folder.
  • A region check. Code interpreter isn't available in every region. Learn's tool pages link to a region and model availability table.

Step 1: decide on web search before you add it

Learn is direct about this. Web search uses Grounding with Bing, which has its own terms. "Customer data flows outside the Azure compliance boundary." The Microsoft Data Protection Addendum doesn't apply to data sent to Grounding with Bing. Only the search query and tool parameters go to Bing, not the whole conversation. A customer's message can still shape that query.

For Harbour Goods, the support lead signs off on one use: public holidays and courier news. If your organisation won't, leave WebSearchTool() out of step 3. Everything else still works.

Step 2: upload the policy pack and the orders

from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient

FOUNDRY_PROJECT_ENDPOINT = "your_project_endpoint"

project = AIProjectClient(
    endpoint=FOUNDRY_PROJECT_ENDPOINT,
    credential=DefaultAzureCredential(),
)
openai = project.get_openai_client()

# File search reads from a vector store
vector_store = openai.vector_stores.create(name="hg-policies")
with open("first-prompt-agent.md", "rb") as f:
    openai.vector_stores.files.upload_and_poll(
        vector_store_id=vector_store.id,
        file=f,
    )

# Code interpreter reads uploaded files
with open("built-in-agent-tools.csv", "rb") as f:
    orders_file = openai.files.create(purpose="assistants", file=f)

print(vector_store.id, orders_file.id)

upload_and_poll waits until the file is indexed. Without the wait, the first question can arrive before the index exists.

Step 3: create version 3 with three tools

from azure.ai.projects.models import (
    AutoCodeInterpreterToolParam,
    CodeInterpreterTool,
    FileSearchTool,
    PromptAgentDefinition,
    WebSearchTool,
)

INSTRUCTIONS = """You are the Harbour Goods customer support agent.
Use file search for any question about returns, delivery, warranty or
support hours. Quote the policy. Use code interpreter for any question
about orders, totals or stores in the orders file. Use web search only for
Indian public holidays and courier news. Valid store codes are ST-003,
ST-007, ST-011, ST-014, ST-019 and ST-022. Flag any other code."""

agent = project.agents.create_version(
    agent_name="harbour-goods-support",
    definition=PromptAgentDefinition(
        model="gpt-5.4-mini",
        instructions=INSTRUCTIONS,
        tools=[
            FileSearchTool(vector_store_ids=[vector_store.id]),
            CodeInterpreterTool(
                container=AutoCodeInterpreterToolParam(file_ids=[orders_file.id])
            ),
            WebSearchTool(),
        ],
    ),
)
print(f"{agent.name}:{agent.version}")

create_version on an existing name adds a version. It doesn't overwrite version 2.

In the portal, open the agent on the Playground tab and look under Tools. The three tools appear on the new version. You can add tools from there too. Learn doesn't name every button in the new tool picker, so the label may read Add or Add tool.

Step 4: ask three questions and see which tool ran

QUESTIONS = [
    "What does the electronics warranty cover?",
    "Which store had the highest order value in March 2026? How much was it?",
    "Is 15 August 2026 a public holiday in India?",
]

for question in QUESTIONS:
    response = openai.responses.create(
        input=question,
        extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
    )
    tools_used = [item.type for item in response.output if item.type.endswith("_call")]
    print(question)
    print("tools:", tools_used or "none")
    print("answer:", response.output_text)

The response.output list holds every item the agent produced, in order. Tool calls show up as file_search_call, code_interpreter_call and web_search_call. The final answer is a message item, which output_text collects for you.

Check it worked

These numbers come from the sample file, computed in Python before writing this article.

QuestionTool you should seeThe answer must say
Warrantyfile_search_call12 months from delivery, manufacturing faults, not accidental or water damage
Highest storecode_interpreter_callST-007 Chennai South, INR 1,07,470 across 11 orders
15 Augustweb_search_callYes, Independence Day, with a cited web source

Two more checks on the orders file, for the code interpreter:

  • "What was total order value in March?" The file holds INR 4,00,310 across 60 rows. One row, HG-260313-0018 for INR 9,410, carries the store code ST-099. A careful answer reports INR 3,90,900 for the six real stores and flags the bad row.
  • "How many orders were returned?" Four, worth INR 10,000 together.

If the agent answers the warranty question with no tool call, it's answering from memory. Make the instruction firmer or set tool_choice="required" on the request while testing.

Where this breaks

  • Code interpreter sessions. Each conversation that calls it gets its own session. Learn says a session is active for up to one hour with a 30 minute idle timeout. Two concurrent conversations mean two sessions and two charges.
  • No internet in the sandbox. Code interpreter can't make outbound network requests. It works only on files you attach.
  • Fixed Python packages. Code interpreter ships a fixed set of data science packages. Anything else needs the custom code interpreter.
  • Stale vector stores. Change the returns policy and the agent still quotes the old one until you upload the new file. Treat the vector store as content that needs an owner.
  • Web search and compliance. Covered in step 1. It's a policy decision, not a technical one.
  • Tools you never see used. If a tool never appears in the output, it's either badly described in the instructions or unnecessary. Remove what isn't earning its keep.

On the brewhouse floor

At Distillery A, the warehouse manager asks three kinds of question about casks. "What does our spec say about refill bourbon barrels?" is file search over the spec. "How many casks in Warehouse 2 are over eight years old?" is code interpreter over the cask register export. "What's the current duty rate change in the news?" is web search, which the compliance lead may well refuse. Same agent, three tools. The response shows which one answered.
