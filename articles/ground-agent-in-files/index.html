Ground an agent in your files with the file search tool

Upload the three Harbour Goods policy documents, put them in a vector store and attach file search to a prompt agent. Six test questions with the answers the agent should give, including one it must refuse and one that needs arithmetic.

12 Oct 2026 Foundry as of October 2026 Checked against Microsoft Learn Level 1 Ankur Napa KnowledgeAgentsToolsSDK

Short answer

The file search tool is the shortest path from "we have some PDFs" to "the agent answers from them". You upload files, add them to a vector store and attach file search to an agent. Foundry parses, chunks and embeds the files for you, then runs hybrid keyword and vector search when the agent calls the tool. You do not build an index or pick an embedding model.

The trade is control. Learn lists the defaults: 800-token chunks with 400 tokens of overlap, text-embedding-3-large at 256 dimensions and up to 20 chunks placed in context. An agent can attach one vector store. A vector store holds up to 10,000 files. File search also carries charges beyond model tokens. When you outgrow those limits, move to Your first Azure AI Search index.

For AI-103, this step sits in Implement generative AI and agentic solutions: building agents that integrate retrieval, plus integrating agent tools such as knowledge stores and search.

What you will build

A Harbour Goods support agent that answers returns, delivery and warranty questions from three policy documents and cites them. It must say so when the documents do not cover a question, rather than guess.

The sample files are short Markdown policies with numbered sections, so you can check every answer by eye:

  • Returns policy, sections R1 to R7.
  • Delivery promise, sections D1 to D6.
  • Warranty terms, sections W1 to W5.

Before you start

  • A Foundry project with a chat model deployment. This article uses gpt-5.4-mini. Use your own deployment name if it differs.
  • The Foundry User role on the project to create and run agents. Learn notes the Foundry roles were renamed recently, so you may still see the old name, Azure AI User.
  • Storage Blob Data Contributor on the project's storage account, which file upload needs.
  • Python 3.9 or later, then pip install azure-ai-projects azure-identity. Sign in with az login so DefaultAzureCredential finds you.
  • The project endpoint from the project overview page. It looks like https://<resource>.services.ai.azure.com/api/projects/<project>.

Know which agent setup you have. In the basic setup, files sit in Microsoft-managed storage and the vector store uses a Microsoft-managed search resource. In the standard setup, both live in the Azure Blob Storage and Azure AI Search resources you connected. The code is identical either way.

Step 1: download the three policies

Save the three Markdown files into a folder called policies next to your script. Markdown is on the supported file type list, as are PDF and Word.

Step 2: create the vector store and the agent

This follows the prompt agent sample on the file search page, with a loop for three files and stricter instructions.

from pathlib import Path

from azure.ai.projects import AIProjectClient
from azure.ai.projects.models import FileSearchTool, PromptAgentDefinition
from azure.identity import DefaultAzureCredential

PROJECT_ENDPOINT = "https://<resource>.services.ai.azure.com/api/projects/<project>"
MODEL = "gpt-5.4-mini"

project = AIProjectClient(endpoint=PROJECT_ENDPOINT, credential=DefaultAzureCredential())
openai = project.get_openai_client()

vector_store = openai.vector_stores.create(name="harbour-goods-policies")

for path in sorted(Path("policies").glob("*.md")):
    with path.open("rb") as handle:
        result = openai.vector_stores.files.upload_and_poll(
            vector_store_id=vector_store.id,
            file=handle,
        )
    print(path.name, result.status)

instructions = (
    "You are the Harbour Goods support agent. "
    "Answer only from the policy files returned by file search. "
    "Quote the section number, such as R2 or W4, for every fact you use. "
    "If the files do not answer the question, say you do not have that information "
    "and suggest calling support between 9 AM and 9 PM IST."
)

agent = project.agents.create_version(
    agent_name="harbour-support-files",
    definition=PromptAgentDefinition(
        model=MODEL,
        instructions=instructions,
        tools=[FileSearchTool(vector_store_ids=[vector_store.id])],
    ),
    description="Answers returns, delivery and warranty questions from policy files.",
)
print(agent.name, agent.version, vector_store.id)

upload_and_poll returns only after ingestion finishes, so each file should print completed. Keep the vector store ID. You need it to clean up.

Step 3: ask the six test questions

questions = [
    "How long do I have to return a product?",
    "I live in Jaipur. When will my order arrive?",
    "My kettle broke after two months. Can I return it?",
    "Is delivery free on an INR 1,500 order?",
    "How much is the extended warranty on an INR 5,000 blender?",
    "Do you match competitor prices?",
]

for q in questions:
    conversation = openai.conversations.create()
    response = openai.responses.create(
        conversation=conversation.id,
        input=q,
        extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
    )
    print(f"Q: {q}\nA: {response.output_text}\n")

Each question gets a fresh conversation so one answer cannot lean on the last.

Step 4: look at it in the portal

In the Foundry portal, select Build, then Agents. Open harbour-support-files. The agent you made in code appears with its file search tool and vector store. Ask a question in the playground and open the trace for the run. You should see a file search tool call before the answer. If the answer arrives with no tool call, the model answered from memory and your instructions need to be firmer.

Check it worked

Every expected answer below was worked out from the sample files.

QuestionExpected answerSections
How long do I have to return a product?30 days from delivery, with the receipt or order IDR2
I live in Jaipur. When will my order arrive?5 working days. Jaipur is not on the metro listD1, D2
My kettle broke after two months. Can I return it?Not as a return, the 30 days have passed. Claim under the 12-month warrantyR2, W1, W4
Is delivery free on an INR 1,500 order?No. Orders below INR 2,000 pay INR 99D3
Extended warranty on an INR 5,000 blender?INR 499. Eight per cent is INR 400, below the INR 499 minimumW5
Do you match competitor prices?Does not know, suggests calling support 9 AM to 9 PM ISTNone

The last two are the useful ones. The blender question checks that the agent applies the minimum instead of quoting 8 per cent. The price match question checks that it refuses. A support agent that invents a price match policy costs real money.

Clean up when you finish:

project.agents.delete_version(agent_name=agent.name, agent_version=agent.version)
openai.vector_stores.delete(vector_store.id)

Where this breaks

  • One vector store per agent. Learn states an agent can attach at most one vector store. A conversation can attach at most one too. Put related files in the same store.
  • Conversation stores expire. Vector stores created through conversation helpers expire seven days after they were last active. Runs on that conversation then fail. The agent's own store does not have this default.
  • File limits. 512 MB per file and no more than 5,000,000 tokens per file. Text files must be UTF-8, UTF-16 or ASCII.
  • Images do not count. File search reads text. A scanned policy with no text layer needs OCR first, which is what Content Understanding is for.
  • No per-user filtering. Learn warns that file search through a toolbox in a hosted agent does not support user isolation. Everyone in the project shares the vector store. Do not upload anything a customer should not read.
  • You cannot tune the chunking. When an answer keeps citing the wrong section, the fix is an index you control. Retrieval quality shows how.

On the brewhouse floor

A winery's cellar door team fields the same questions every weekend: can a case be shipped interstate, how long will an order take, what happens if a bottle arrives corked. The answers sit in three documents nobody reads. Upload those to a vector store, attach file search and the cellar hand gets an answer with the section number in seconds. Test the corked bottle question first. If the agent promises a refund the policy only gives as a replacement, the winery hears about it from every customer who asks.
