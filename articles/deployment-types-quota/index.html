Deployment types and quota: Global, Data Zone, Provisioned or Batch

Pick a deployment type from where data may be processed and how you want to pay, then size tokens per minute from real traffic instead of guessing.

12 Oct 2026 Foundry as of October 2026 Checked against Microsoft Learn Level 2 Ankur Napa ModelsCostGovernance

Short answer

A deployment type answers two questions. Where may my prompts be processed? How do I pay? Start with Global Standard: it gets new models first, has the lowest price and the broadest regions. Move only for a reason: data residency (Data Zone or Standard), reserved throughput (Provisioned) or large jobs that can wait a day (Batch).

Then size quota in tokens per minute (TPM). The rate limiter counts your prompt plus the max_tokens you ask for, not just the tokens you are billed for. Size for that, at peak, with headroom.

This step covers the AI-103 skill area Plan and manage an Azure AI solution: choosing deployment options and managing quotas, scaling, rate limits and cost footprints.

Data at rest stays in your resource's geography for every type. The type only changes where inference runs. New types arrive in order: Global first, then Data Zone, then geography-based. Geography-based types have no guaranteed date.

For Harbour Goods, the choices fall out of the workloads:

WorkloadTypeReason
Support assistantGlobal StandardBursty daytime traffic, no residency rule on chat text.
Nightly product descriptionsGlobal BatchHundreds of rows, done by morning, at half the per-token price.
Supplier invoice extractionData Zone Standard or StandardFinance wants processing kept in a defined boundary.

One check before you pick a Data Zone type from India: the APAC data zone covers multiple Asia Pacific regions and Microsoft can add regions without notice. Read the per-region list on Foundry Models sold by Azure for your resource's region. Don't assume.

Step 2: size the quota from traffic

Quota is granted per subscription, per model and per deployment type, in TPM. You hand slices of it to deployments. Each slice sets that deployment's TPM limit and a matching requests-per-minute (RPM) limit. The RPM to TPM ratio varies by model. In the October 2026 tier tables, gpt-5.4-mini on Global Standard runs at 1 RPM per 1,000 TPM.

Two rules from Learn shape the sizing:

  • The TPM limiter estimates each request from the prompt and the max_tokens setting at the moment it arrives. It isn't the billed count.
  • The RPM limiter checks short windows, typically 1 or 10 seconds. A burst inside one second can trip it even when the minute total looks fine.

The sample file has hourly traffic for one day of the support assistant, 9 AM to 9 PM IST. Compute the sizing in Python:

import csv

MAX_OUTPUT_TOKENS = 400   # the cap you will set on each request
BURST = 3                 # peak minute versus the average minute in the peak hour

rows = list(csv.DictReader(open("deployment-types-quota.csv")))
peak = max(rows, key=lambda r: int(r["requests"]))
rpm = int(peak["requests"]) / 60
billed_tpm = rpm * (int(peak["avg_input_tokens"]) + int(peak["avg_output_tokens"]))
limit_tpm = rpm * (int(peak["avg_input_tokens"]) + MAX_OUTPUT_TOKENS)

print("peak hour:", peak["hour_ist"], "requests:", peak["requests"])
print("average RPM in peak hour:", rpm)
print("billed TPM:", billed_tpm)
print("rate-limit TPM:", limit_tpm)
print("sized TPM with burst:", limit_tpm * BURST, "sized RPM:", rpm * BURST)

Round up to 100,000 TPM. At 1 RPM per 1,000 TPM that also gives 100 RPM, comfortably over 51. In October 2026, a Tier 1 subscription gets 1,000,000 TPM of Global Standard quota for gpt-5.4-mini, so this deployment uses a tenth of it.

Step 3: check your quota and tier

  1. In the Foundry portal, select Manage > Quota.
  2. On the Token per minute tab, select a deployment to see its allocation, its usage and the other deployments sharing the same quota.
  3. To free quota, select the pencil icon in Affiliated deployments using shared quota and lower another deployment.
  4. To ask for more, select Request quota. Allow up to 15 minutes for edits to apply.

Your quota tier sets the ceiling. Tiers run from Free and Tier 1 to Tier 6 and rise with usage. Check yours from Python:

import json
import requests
from azure.identity import DefaultAzureCredential

SUBSCRIPTION_ID = "<your-subscription-id>"
token = DefaultAzureCredential().get_token("https://management.azure.com/.default")
url = (
    f"https://management.azure.com/subscriptions/{SUBSCRIPTION_ID}"
    "/providers/Microsoft.CognitiveServices/quotaTiers?api-version=2025-10-01-preview"
)
response = requests.get(url, headers={"Authorization": f"Bearer {token.token}"})
print(json.dumps(response.json(), indent=2))

The response shows currentTierName, such as Tier 1.

Step 4: deploy with the sized capacity

In the portal, select Build > Models > Deploy > Deploy a base model, pick the model, then choose Custom settings instead of Default settings. Set the deployment type and the TPM there.

With the CLI, capacity is set in units of 1,000 TPM:

az cognitiveservices account deployment create \
    --name hg-foundry-dev \
    --resource-group hg-foundry-dev-rg \
    --deployment-name support-mini \
    --model-name gpt-5.4-mini \
    --model-version "2026-03-17" \
    --model-format OpenAI \
    --sku-capacity 100 \
    --sku-name GlobalStandard

Then set max_output_tokens=400 on every Responses call, so the rate limiter's estimate matches the plan.

Step 5: block a type with Azure Policy

If finance must never see invoices processed outside a boundary, block Global Standard on that resource. This rule matches deployments by SKU name. Assign it with a deny effect.

{
    "mode": "All",
    "policyRule": {
        "if": {
            "allOf": [
                {
                    "field": "type",
                    "equals": "Microsoft.CognitiveServices/accounts/deployments"
                },
                {
                    "field": "Microsoft.CognitiveServices/accounts/deployments/sku.name",
                    "equals": "GlobalStandard"
                }
            ]
        }
    }
}

Check it worked

  • az cognitiveservices account deployment show --name hg-foundry-dev --resource-group hg-foundry-dev-rg --deployment-name support-mini --query "{sku:sku.name, capacity:sku.capacity}" returns GlobalStandard and 100.
  • Manage > Quota shows 100,000 TPM against support-mini.
  • A load test at 51 requests per minute, spread evenly, returns no 429 responses.
  • With the policy assigned, a new Global Standard deployment on the finance resource fails with a policy error.

Where this breaks

  • 429s below quota. Uneven bursts trip the per-second RPM check. Spread requests, retry with backoff and keep max_output_tokens close to real answer length.
  • Quota is shared. Deployments of the same model and type draw on one pool. Since 7 May 2026, Foundry is moving quota to subscription-level pools, starting with some realtime models and soon all models. Under that scheme, Global Standard deployments of one model version share a pool across every region in the subscription.
  • Usage tiers and latency. Above your usage tier, latency can vary and can be more than two times higher. Provisioned is the fix when that matters.
  • Provisioned is a commitment. You pay per PTU per hour whether you use it or not. Global and Data Zone provisioned deployments start at 15 PTUs for many models. Regional ones often start at 50.
  • Batch is not a fast lane. Batch targets 24 hours and has no real-time SLA. It has its own enqueued-token quota, so it never steals from your online traffic.
  • Developer type expires. It deletes itself after 24 hours. Never point an app at it.
  • Not every model has every type. Check availability before you promise a type to a compliance team.

On the brewhouse floor

Brewery A's shift handover assistant is quiet all night and busy for twenty minutes at 6 AM, when every supervisor asks for the overnight summary at once. Sizing from the daily average would starve that rush. Size from the busiest minute, with room for the burst. Then the 6 AM queue clears. The nightly batch that drafts the tank report for FV-03 can wait for Global Batch at half the per-token price.
